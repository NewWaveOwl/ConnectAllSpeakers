JLayer 1.0.1 — MP3 decoder/player/converter library for Java
Published by JavaZOOM; decoder portions include work by Tobias Bading,
Berlin University of Technology, Jeff Tsay and the contributors identified in
the corresponding source headers.

Only the decoder API is used. The published binary is unmodified and remains
a separate, replaceable JAR in the desktop application's app directory.
JLayer is distributed under GNU Library GPL version 2 or, at your option,
any later version; the LGPL 2.1 license text is included as LGPL-2.1.txt.

Corresponding source is included unmodified as jlayer-1.0.1-sources.jar beside
this notice inside the desktop resource archive. The published Maven POM is
included separately as jlayer-1.0.1.pom. Extract the source archive into
src/main/java beneath that POM before rebuilding with Maven; preserve its
serialized decoder tables alongside the Java sources.
Modifying/replacing this library and reverse engineering for debugging such
modifications are permitted by the accompanying license. Preserve its classpath
filename from the launcher configuration when replacing the JAR.
